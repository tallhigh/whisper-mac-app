The first release. Whisper Transcriber turns recordings into text on your own Mac —
no terminal, no API key, no account, and nothing uploaded anywhere.

### Transcribe files

Drag audio or video onto the window and queue as many files as you like; they run
one after another with their own progress and a cancel button, and the text
streams in as it is produced. `m4a`, `mp3`, `wav`, `aiff`, `flac`, `ogg`, `opus`,
`aac`, `caf`, `wma`, `mp4`, `mov`, `m4v`, `mkv`, `webm` and `avi` all work, and
dropping a folder picks up the supported files inside it.

### Record with live transcription

Press ⇧⌘R and the words appear about two seconds behind your voice. Record the
microphone, the system audio of an app you choose, or both at once to capture both
sides of a call. When you stop, the saved recording goes through a full-quality
pass, so the live text is a preview and the file you keep is the accurate one.

### Six output formats

`txt` for plain text, `srt` and `vtt` for subtitles, `json` and `tsv` for
timestamps and segment data, and `notes` — a timestamped Markdown list that turns a
recording into something you can skim:

```markdown
- [00:00] Today the main topic was the budget lines.
- [02:17] We went over three separate headings.
```

### Built to fit how you work

- 14 Whisper models from `tiny` to `large-v3` plus the `turbo` variants, with the
  ones you already have on disk shown alongside their size
- 100 languages or automatic detection, and a translate task that writes English
  whatever the source language is
- Four built-in presets, plus your own saved combinations of model, language and
  format
- Output next to the source file or in a folder you pick, with overwrite protection
- Keep the Mac awake while it works, get a notification when it finishes, reveal
  the files in Finder
- Apple Silicon GPU or CPU, with an automatic retry on the CPU if the GPU path
  fails on a file

### Private and self-contained

Everything runs on your Mac. The app installs a Python environment of its own under
`~/Library/Application Support/WhisperTranscriber/` and never touches your system
Python, Homebrew or `PATH`. Models you already have in `~/.cache/whisper` are used
as they are. Once set up, it works offline.

The app and the `.dmg` are signed with an Apple Developer ID, notarized and
stapled, so there is no Gatekeeper warning and no internet needed to open them.
